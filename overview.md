
modular motor controller

This should be the best, most versatile motor control firmware ever!  
* It should be runnable on a PC against a virtual motor with an abstracted hardware layer
* It should compile effciently
* It should be able to run on an STM32 - (STM32G474 to start)
* It should be super effcient and easy to tune
* It should have an interface that allows for high bandwidth moniotring for evaluation of the system
* It should be able to profile a motor automotically, this should be done by streaming data to the host to offload processing
* It should be able to do torque, speed, and position control
* Decide on the best language for the job
* It needs to be scaleable for low resource systems like an M0 ARM or a fast GPU
* Multiple control methodolgies would be nice to make this scaleable, traditional low resource and cutting edge advanced
