These are the profiler's runtime parameters. The control loop needs the R it actually drives through — winding plus the board's shunt and driver FETs — so the r param reads higher than any datasheet or multimeter value; the line above shows the at-the-motor equivalent (wye winding assumed), and the meter entry adds the path back on for you. Edits (highlighted) take effect at the next clean drive start and live in RAM only — they reset to firmware defaults on power-cycle. Out-of-range values are rejected by the firmware; the range is shown beside each field.
